# ComfortPro HVAC & Plumbing

A modern, responsive website concept for an HVAC and plumbing company serving Northern Virginia.

## Live Demo

https://comfortpro-demo-61krepktf-ruchit8-3346.vercel.app

## Overview

ComfortPro is a portfolio demonstration focused on helping local service businesses turn website visitors into customer inquiries.

The project includes:

- Responsive mobile-first design
- Multi-step service estimate form
- Click-to-call functionality
- HVAC and plumbing service sections
- Service-area presentation
- Conversion-focused calls to action
- Modern, professional UI

## Tech Stack

- React
- Next.js
- TypeScript
- Tailwind CSS
- Vercel

## Purpose

This is a fictional business website created as a portfolio project. ComfortPro is not an actual HVAC or plumbing company.
